# How to Use Web3 Authentication Endpoints

## 1. Get Nonce

**Endpoint:**
```
POST /auth/web3/nonce
```

**Request:**

Send a JSON body with your wallet address:

```json
{
  "address": "0x5c5c5a76b4d225122822482cd62d640ebbd0e8504"
}
```

**Response:**

```json
{
  "nonce": "4f9ac2cf-24ca-4bae-9771-61de16bf1978",
  "message": "Login to App with address: 0x5c5c5a76b4d225122822482cd62d640ebbd0e8504\nNonce: 4f9ac2cf-24ca-4bae-9771-61de16bf1978\nTimestamp: 2025-08-13T05:25:02.724Z",
  "expiresIn": 1080000
}
```

**Message Format Example:**

```
Login to App with address: 0x5cc5a76b4d225122822482cd62d640ebbd0e8504
Nonce: 24e99070-bc2c-4a7c-a52e-6e40e1561a6b
Timestamp: 2025-07-21T07:37:33.105Z
```

- `nonce`: Unique value for signing.
- `message`: Message to sign with your wallet.
- `expiresIn`: Expiry time in milliseconds.

## 2. Authenticate with Signature

**Endpoint:**
```
POST /auth/web3
```

**Request:**

Send a JSON body with your wallet address and the signature (signed message from step 1):

```json
{
  "signer": "0x5c5c5a76b4d225122822482cd62d640ebbd0e8504",
  "signature": "0x9ebb976e21359b7442fc1aa6b37a2af9d9b52b32c8120efa45d2334d2be6a4fc5f6908858411396084ee3a441fc49c3cce514052075b448bac0dacf..."
}
```

**How it works:**

- The `signature` is generated by using your blockchain wallet to sign the `message` received from `/auth/web3/nonce`.
- The backend will verify the signature and authenticate your wallet address.

## Usage Steps

1. Send your wallet address to `/auth/web3/nonce`.
2. Receive the nonce and message.
3. Use your wallet to sign the message.
4. Send your address and signature to `/auth/web3` to authenticate.
